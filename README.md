# 🌿 ReWear AI (SmartFashion) — ИИ-эко-гардероб

**Telegram-бот против фаст-фэшн. Проект для хакатона VentureHack 2026.**

## 🎯 Проблема
Индустрия фаст-фэшн производит огромное количество одежды, которая быстро выходит из моды и отправляется на свалку. Люди тратят деньги на ненужные вещи и увеличивают углеродный след планеты.

## 💡 Наше решение
ReWear AI помогает покупать меньше, носить то, что уже есть, и осознанно относиться к гардеробу.

### 🚀 Основные функции
- 🛑 **Стоп-покупка:** Анализ вещи из магазина. Бот оценивает состав ткани, финансовую выгоду и предлагает альтернативу из вашего шкафа.
- ✨ **Вторая жизнь вещи:** Стилизация забытых вещей. ИИ подбирает 3 модных образа из имеющейся одежды.
- 📊 **Мой эко-след:** Геймифицированная статистика сэкономленного CO₂, денег и эко-ранг пользователя.

## 🛠️ Технологии
- Python 3.14
- Aiogram 3 (асинхронный Telegram Bot API)
- FSM (Finite State Machine) для управления диалогами

## 🚀 Как запустить бота

**1. Клонируйте репозиторий:**

    git clone https://github.com/amiko577/SmartFashion.git
    cd SmartFashion

**2. Установите зависимости:**

    pip install -r requirements.txt

**3. Создайте файл `config.py` и поместите туда свой токен от @BotFather:**

    TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"

**4. Запустите бота:**

    python main.py
