# 🌿 SmartFashion — ИИ-эко-гардероб

**Telegram-бот, который распознаёт одежду по фото и напоминает, почему важно носить её дольше. Проект для хакатона VentureHack 2026.**

## 🎯 Проблема

Индустрия фаст-фэшн производит более 100 млрд вещей в год, из которых примерно треть отправляется на свалку, не будучи ни разу надетой. На одну пару джинсов уходит до 7500 литров воды, а текстильная промышленность отвечает за ~10 % всех выбросов CO₂ на планете.

Люди покупают больше, чем могут носить, и не задумываются о реальной цене вещи — не в деньгах, а в ресурсах планеты.

## 💡 Наше решение

SmartFashion помогает осознанно относиться к гардеробу: по одной фотографии вещи бот определяет её характеристики, показывает **эко-след производства** и даёт **персональные советы**, как продлить жизнь этой вещи.

### 🚀 Основные функции

- 🎨 **Распознавание цвета одежды** — 22 оттенка: от базовых (белый, чёрный, синий) до сложных (оливковый, мятный, бордовый, лавандовый). Алгоритм анализирует центральную зону фото, автоматически отделяет фон по углам изображения и определяет доминирующий цвет с приоритетом хроматических оттенков.
- 👕 **Определение типа одежды** — верх / низ / платье. Работает на модели `fashion-clip`, заточенной под fashion-изображения, с усреднением по нескольким промптам на каждый класс.
- 🌍 **Эко-след вещи** — оценка затраченной воды и выброшенного CO₂ на производство вещи в зависимости от её типа.
- 💡 **Эко-советы** — база из практических советов по устойчивой моде и интересных фактов об индустрии. Каждое распознавание = новый совет.
- 🌱 **Кнопка «Эко-совет»** — быстрый доступ к случайной паре «совет + факт» без отправки фото.

## 🛠️ Технологии

- **Python 3.14**
- **Aiogram 3** — асинхронный Telegram Bot API
- **FashionCLIP** (`patrickjohncyh/fashion-clip`) — визуально-языковая модель, обученная на fashion-датасетах
- **PyTorch** — инференс модели на CPU/GPU
- **Pillow + NumPy** — обработка изображений и векторная классификация цветов по HSV

## 📦 Установка и запуск

**1. Клонируйте репозиторий:**

    git clone https://github.com/amiko577/SmartFashion.git
    cd SmartFashion

**2. Установите зависимости:**

    pip install -r requirements.txt

**3. Создайте `config.py` рядом с `main.py` и вставьте туда токен от [@BotFather](https://t.me/BotFather):**

    TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"

**4. Запустите бота:**

    python main.py

При первом запуске бот автоматически скачает модель `fashion-clip` (~600 МБ) с Hugging Face. Загрузка модели идёт в фоне, поэтому бот сразу отвечает на команды и уже умеет определять цвет — тип появится через минуту, когда модель догрузится.

## 🧠 Как это работает

**Цвет.** Изображение уменьшается до 200×200, по 4 углам вычисляется медианный цвет фона. Берётся центральная зона (там обычно находится вещь) и отбрасываются пиксели, близкие к фону. Оставшиеся пиксели классифицируются по HSV: получаем имя оттенка, затем берётся самый частый. Если хроматический цвет занимает хотя бы 25 % — он побеждает ахроматический (это защищает от ложного «белого» на белых полосках одежды).

**Тип.** Через FashionCLIP сравниваются 8 промптов на верх (`t-shirt`, `shirt`, `sweater`, `hoodie`…), 6 на низ (`jeans`, `trousers`, `skirt`…) и 4 на платье. Логиты усредняются по классу, применяется softmax — выбирается класс с максимальной уверенностью. Если уверенность ниже 45 %, бот честно сообщает «не удалось определить», а не гадает.

## 📸 Как получить лучший результат

- Однотонный фон — контрастный к цвету вещи (белая футболка → тёмный стол, чёрные джинсы → светлая поверхность).
- Вещь целиком в кадре, не обрезана по краям.
- Хорошее естественное освещение, без резких теней.
- Без других вещей и людей в кадре.
